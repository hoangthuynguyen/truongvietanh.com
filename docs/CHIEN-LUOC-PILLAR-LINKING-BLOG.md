## PHẦN 4: CHIẾN LƯỢC INTERNAL LINKING

### 4A. QUY TẮC LIÊN KẾT GIỮA CÁC TẦNG

```
Quy tắc 1: MỖI TRANG phải có ít nhất 3 internal links
Quy tắc 2: Link LUÔN chứa anchor text = keyword target của trang đích
Quy tắc 3: Link lên (child → parent) = contextual, trong nội dung
Quy tắc 4: Link xuống (parent → child) = section cuối "Chủ đề liên quan"
Quy tắc 5: Link ngang (sibling → sibling) = so sánh, "xem thêm"
Quy tắc 6: KHÔNG link ra ngoài site trừ nguồn uy tín (xem Phần 5)
```

### 4C. QUY TẮC ANCHOR TEXT

```
✅ ĐÚNG:
- "chương trình mầm non song ngữ" → /mam-non/chuong-trinh
- "học phí tiểu học 2026" → /hoc-phi/tieu-hoc
- "trường song ngữ quận Gò Vấp" → /co-so/go-vap

❌ SAI:
- "xem thêm" → bất kỳ trang nào (anchor rỗng, không SEO value)
- "click here" → không bao giờ dùng
- "trang này" → không keyword value
- "trường việt anh mầm non song ngữ quận gò vấp tphcm" → quá dài, over-optimized
```

**Quy tắc:**
- Anchor text = 3-7 từ, chứa keyword chính của trang đích
- Mỗi trang đích chỉ dùng 2-3 biến thể anchor text, không spam cùng 1 anchor
- Biến thể tự nhiên: "mầm non song ngữ" / "chương trình mầm non" / "mầm non Việt Anh"

## PHẦN 5: CHIẾN LƯỢC EXTERNAL LINKING

### 5A. NGUYÊN TẮC

```
1. CHỈ link ra khi cần dẫn chứng từ nguồn uy tín (E-E-A-T)
2. KHÔNG link đến đối thủ (Vinschool, BVIS, AIS, v.v.)
3. Mỗi bài 1-3 external link, KHÔNG hơn
4. Dùng rel="noopener noreferrer" cho tất cả external link
5. Ưu tiên nguồn .gov, .edu, tổ chức quốc tế
6. KHÔNG link đến trang affiliate, trang review không kiểm soát
```
